线性回归

回归（regression）用于建立一个或多个自变量与因变量之间的关系。机器学习中的回归任务通常用于预测连续数值，例如房价、股票价格、住院时间、销量需求等。

回归与分类的区别在于：

  • 回归：预测一个数值，例如房价为 120 万元；
  • 分类：预测一个类别，例如图片属于“猫”还是“狗”。

基本元素

以房价预测为例，假设我们通过房屋面积和房龄预测房屋价格。

常见术语如下:

名称 含义 例子

样本 / 数据点 数据集中的一行 一套房子的记录
特征 / 协变量 用于预测的输入变量 面积、房龄
标签 / 目标 需要预测的输出变量 房价

线性模型

线性回归假设输入特征与输出之间近似满足线性关系。

对于房价预测问题，可以写成：

price=warea⋅area+wage⋅age+b\mathrm{price} = w_{\mathrm{area}} \cdot \mathrm{area} + w_{\mathrm{age}} \cdot \mathrm{age} + b price=warea​⋅area+wage​⋅age+b

其中：

  • wareaw_{\mathrm{area}}warea​、wagew_{\mathrm{age}}wage​ 是权重（weight），决定不同特征对预测值的影响；
  • bbb 是偏置（bias），也称偏移量或截距；
  • 偏置项可以提升模型表达能力，使模型不被迫经过原点。

一般形式为：

y^=w1x1+w2x2+⋯+wdxd+b\hat{y} = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b y^​=w1​x1​+w2​x2​+⋯+wd​xd​+b

将所有特征放到向量 x∈Rd\mathbf{x} \in \mathbb{R}^dx∈Rd 中，并将所有权重放到向量 w∈Rd\mathbf{w} \in \mathbb{R}^dw∈Rd 中，

可以得到向量形式：

y^=w⊤x+b\hat{y} = \mathbf{w}^\top \mathbf{x} + b y^​=w⊤x+b

其中：

  • x\mathbf{x}x 是输入特征向量；
  • w\mathbf{w}w 是权重向量；
  • bbb 是偏置；
  • y^\hat{y}y^​ 是预测值。

对于整个数据集，记 nnn 个样本构成的特征集合矩阵为 X∈Rn×d\mathbf{X} \in \mathbb{R}^{n \times d}X∈Rn×d ，预测值为 y^∈Rn\hat{\mathbf{y}} \in \mathbb{R}^ny^​∈Rn ，有：

y^=Xw+b\hat{\mathbf{y}} = \mathbf{X}\mathbf{w} + b y^​=Xw+b

严格来说，带有偏置项的线性模型是一个仿射变换（affine transformation）：先通过权重做线性变换，再通过偏置做平移。

平方损失的概率解释

正态分布（normal distribution），也称高斯分布（Gaussian distribution）。若随机变量 xxx 的均值为 μ\muμ，方差为 σ2\sigma^2σ2，标准差为 σ\sigmaσ，其概率密度函数为：

p(x)=12πσ2exp⁡(−12σ2(x−μ)2)p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{1}{2\sigma^2}(x-\mu)^2 \right) p(x)=2πσ2​1​exp(−2σ21​(x−μ)2)

线性回归常用均方误差，一个重要原因是可以假设观测值中含有正态噪声：

y=w⊤x+b+ϵy = \mathbf{w}^\top\mathbf{x} + b + \epsilon y=w⊤x+b+ϵ

其中：

ϵ∼N(0,σ2)\epsilon \sim \mathcal{N}(0, \sigma^2) ϵ∼N(0,σ2)

在给定输入 x\mathbf{x}x 的情况下，观察到标签 yyy 的概率为：

P(y∣x)=12πσ2exp⁡(−12σ2(y−w⊤x−b)2)P(y \mid \mathbf{x}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{1}{2\sigma^2} (y - \mathbf{w}^\top\mathbf{x} - b)^2 \right) P(y∣x)=2πσ2​1​exp(−2σ21​(y−w⊤x−b)2)

整个数据集的似然为：

P(y∣X)=∏i=1np(y(i)∣x(i))P(\mathbf{y}\mid\mathbf{X}) = \prod_{i=1}^{n} p(y^{(i)} \mid \mathbf{x}^{(i)}) P(y∣X)=i=1∏n​p(y(i)∣x(i))

最大化似然等价于最小化负对数似然：

−log⁡P(y∣X)=∑i=1n12log⁡(2πσ2)+12σ2(y(i)−w⊤x(i)−b)2-\log P(\mathbf{y}\mid\mathbf{X}) = \sum_{i=1}^{n} \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2} \left(y^{(i)} - \mathbf{w}^\top\mathbf{x}^{(i)} - b\right)^2 −logP(y∣X)=i=1∑n​21​log(2πσ2)+2σ21​(y(i)−w⊤x(i)−b)2

当 σ\sigmaσ 被看作固定常数时，第一项与参数无关，第二项除常数外与均方误差相同。因此，在高斯噪声假设下，最小化均方误差等价于对线性模型做极大似然估计。

解析解

线性回归是一个特殊且简单的优化问题，它存在解析解。若将偏置项合并进参数向量中，线性回归的优化目标可写为：

min⁡w∥y−Xw∥2\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2 wmin​∥y−Xw∥2

其解析解为：

w∗=(X⊤X)−1X⊤y\mathbf{w}^* = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y} w∗=(X⊤X)−1X⊤y

解析解的优点是形式明确，便于数学分析；缺点是适用范围有限。

深度学习中的大多数模型没有简单解析解，或者直接求解代价过高，因此通常采用迭代优化方法。

随机梯度下降

梯度下降（gradient descent）的思想是：沿着损失函数下降的方向更新参数。

如果每次更新都使用整个训练集，计算代价可能很高。实际训练中常用小批量随机梯度下降（minibatch stochastic gradient descent）：每次随机抽取一小批样本，用这部分样本估计梯度并更新参数。

设小批量样本集合为 B\mathcal{B}B，批量大小为 ∣B∣|\mathcal{B}|∣B∣，学习率为 η\etaη，参数更新形式为：

(w,b)←(w,b)−η∣B∣∑i∈B∂(w,b)l(i)(w,b)(\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \partial_{(\mathbf{w}, b)} l^{(i)}(\mathbf{w}, b) (w,b)←(w,b)−∣B∣η​i∈B∑​∂(w,b)​l(i)(w,b)

对于线性回归，具体更新为：

w←w−η∣B∣∑i∈Bx(i)(w⊤x(i)+b−y(i))\mathbf{w} \leftarrow \mathbf{w} - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \mathbf{x}^{(i)} \left(\mathbf{w}^\top\mathbf{x}^{(i)} + b - y^{(i)}\right) w←w−∣B∣η​i∈B∑​x(i)(w⊤x(i)+b−y(i))

b←b−η∣B∣∑i∈B(w⊤x(i)+b−y(i))b \leftarrow b - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \left(\mathbf{w}^\top\mathbf{x}^{(i)} + b - y^{(i)}\right) b←b−∣B∣η​i∈B∑​(w⊤x(i)+b−y(i))

基本训练流程：

  1. 初始化模型参数 w\mathbf{w}w 和 bbb；
  2. 随机抽取一个小批量样本；
  3. 计算预测值；
  4. 计算损失；
  5. 计算梯度；
  6. 按学习率更新参数；
  7. 重复上述步骤，直到损失足够小或达到训练轮数。

神经网络图

线性回归可以看作一个非常简单的神经网络。

对于输入：

x1,x2,…,xdx_1, x_2, \ldots, x_d x1​,x2​,…,xd​

输出为：

o1=w⊤x+bo_1 = \mathbf{w}^\top\mathbf{x} + b o1​=w⊤x+b

输入层只负责提供数据，通常不计入网络层数。真正发生计算的是输出层，因此线性回归可以看作：

  • 一个单层神经网络；
  • 一个只有一个人工神经元的网络；
  • 一个全连接层或稠密层，因为每个输入都连接到输出。

softmax 回归

softmax 回归实际上解决的是分类问题。

回归问题关注的是预测一个连续数值；分类问题关注的是判断样本属于哪一个类别。

分类问题通常描述两个有微妙差别的问题：

  1. 硬类别（hard class）：只关心最终属于哪个类别。
  2. 软类别（soft class）：关心样本属于每个类别的概率。

即使最终只需要输出一个类别，模型通常仍会先估计每个类别的概率，再选择概率最大的类别作为预测结果。

分类标签的表示

假设一个图像分类任务中，每张图像属于 {\{{猫,鸡,狗}\}} 三个类别之一，

一种简单的表示方式是用整数标签：

y∈{1,2,3}y \in \{1,2,3\} y∈{1,2,3}

如果类别间有一些自然顺序，那么实际上变成了回归问题，保留这种格式是有意义的。

但事实上，对于一般分类任务，类别间通常没有自然顺序。因此更常用的是独热编码（one-hot encoding）.

独热编码用一个长度等于类别数的向量表示类别：

y∈{(1,0,0),(0,1,0),(0,0,1)}y \in \{(1,0,0),(0,1,0),(0,0,1)\} y∈{(1,0,0),(0,1,0),(0,0,1)}

例如：

类别 one-hot 标签
猫 (1,0,0)(1,0,0)(1,0,0)
鸡 (0,1,0)(0,1,0)(0,1,0)
狗 (0,0,1)(0,0,1)(0,0,1)

其中，真实类别对应的位置为 111，其他位置为 000。

网络结构

对于 qqq 个类别，模型需要输出 qqq 个值，每个值对应一个类别。

假设输入是一个 2×22\times22×2 的灰度图像，将四个像素展平成四个特征：

x=(x1,x2,x3,x4)\mathbf{x} = (x_1,x_2,x_3,x_4) x=(x1​,x2​,x3​,x4​)

o1=x1w11+x2w12+x3w13+x4w14+b1,o2=x1w21+x2w22+x3w23+x4w24+b2,o3=x1w31+x2w32+x3w33+x4w34+b3.\begin{aligned} o_1 &= x_1 w_{11} + x_2 w_{12} + x_3 w_{13} + x_4 w_{14} + b_1,\\ o_2 &= x_1 w_{21} + x_2 w_{22} + x_3 w_{23} + x_4 w_{24} + b_2,\\ o_3 &= x_1 w_{31} + x_2 w_{32} + x_3 w_{33} + x_4 w_{34} + b_3. \end{aligned} o1​o2​o3​​=x1​w11​+x2​w12​+x3​w13​+x4​w14​+b1​,=x1​w21​+x2​w22​+x3​w23​+x4​w24​+b2​,=x1​w31​+x2​w32​+x3​w33​+x4​w34​+b3​.​

这里的 o1,o2,o3o_1,o_2,o_3o1​,o2​,o3​ 通常称为 logits，即进入 softmax 之前的未规范化输出。

用矩阵形式可以写成：

o=Wx+b\mathbf{o} = \mathbf{W}\mathbf{x} + \mathbf{b} o=Wx+b

其中：

  • x∈Rd\mathbf{x}\in\mathbb{R}^{d}x∈Rd：输入特征；
  • W∈Rq×d\mathbf{W}\in\mathbb{R}^{q\times d}W∈Rq×d：权重矩阵；
  • b∈Rq\mathbf{b}\in\mathbb{R}^{q}b∈Rq：偏置向量；
  • o∈Rq\mathbf{o}\in\mathbb{R}^{q}o∈Rq：每个类别对应的 logit。

softmax 回归和线性回归一样，都可以看作单层神经网络。

区别在于：线性回归通常输出一个连续值，softmax 回归输出多个类别对应的值。

softmax 运算

注意到未规范化的预测 o\mathbf{o}o 不能直接看作概率，因为：

  1. logit 可能为负数；
  2. 多个 logit 的和不一定等于 111。

而概率分布需要满足：

  1. 0≤y^j≤10 \leq \hat{y}_j \leq 10≤y^​j​≤1
  2. ∑jy^j=1\sum_j \hat{y}_j = 1∑j​y^​j​=1

softmax 函数可以把任意实数向量转换成概率分布。

给定 logit 向量 o\mathbf{o}o ，softmax 输出为：

y^=softmax(o)其中y^j=exp⁡(oj)∑kexp⁡(ok)\hat{\mathbf{y}} = \mathrm{softmax}(\mathbf{o})\quad \text{其中}\quad \hat{y}_j = \frac{\exp(o_j)}{\sum_k \exp(o_k)} y^​=softmax(o)其中y^​j​=∑k​exp(ok​)exp(oj​)​

softmax 函数将未规范化的预测变换为非负数且总和为 111 ，同时让模型保持 可导 的性质。

softmax 函数不改变 logit 之间的大小次序，因此预测类别可以写成：

argmax⁡jy^j=argmax⁡joj\operatorname*{argmax}_j \hat y_j = \operatorname*{argmax}_j o_j jargmax​y^​j​=jargmax​oj​

虽然 softmax 是非线性函数，但 softmax 回归的 logit 仍由输入特征的仿射变换决定，因此 softmax 回归仍属于线性模型。

小批量样本的矢量化

对于一个小批量样本，设特征维度（输入数量）为 ddd ，批量大小为 nnn ，类别数（输出数量）为 qqq ，

则小批量样本的特征为 X∈Rn×d\mathbf{X} \in \mathbb{R}^{n \times d}X∈Rn×d ，权重为 W∈Rd×q\mathbf{W} \in \mathbb{R}^{d \times q}W∈Rd×q ，偏置为 b∈R1×q\mathbf{b} \in \mathbb{R}^{1\times q}b∈R1×q ，有：

O=XW+b,Y^=softmax(O)\begin{split}\begin{aligned} \mathbf{O} &= \mathbf{X} \mathbf{W} + \mathbf{b}, \\ \hat{\mathbf{Y}} & = \mathrm{softmax}(\mathbf{O}) \end{aligned}\end{split} OY^​=XW+b,=softmax(O)​​

其中 O∈Rn×q\mathbf{O}\in\mathbb{R}^{n\times q}O∈Rn×q , Y^∈Rn×q\hat{\mathbf{Y}}\in\mathbb{R}^{n\times q}Y^∈Rn×q 。

每一行对应一个样本，每一列对应一个类别。 softmax 运算可以按行（rowwise） 执行：对于 O\mathbf{O}O 的每一行，我们先对所有项进行幂运算，然后通过求和对它们进行标准化。

交叉熵损失

softmax 输出可以解释为条件概率 y^j=P(y=j∣x)\hat{y}_j = P(y=j\mid \mathbf{x})y^​j​=P(y=j∣x) 。

对于包含 nnn 个样本的数据集，整体似然为 P(Y∣X)=∏i=1nP(y(i)∣x(i))P(\mathbf{Y}\mid\mathbf{X})=\prod_{i=1}^{n}P(\mathbf{y}^{(i)}\mid\mathbf{x}^{(i)})P(Y∣X)=∏i=1n​P(y(i)∣x(i)) 。

训练目标是让真实标签出现的概率尽可能大，即最大化似然。等价地，可以最小化负对数似然：

−log⁡P(Y∣X)=∑i=1n−log⁡P(y(i)∣x(i))-\log P(\mathbf{Y}\mid\mathbf{X}) = \sum_{i=1}^{n} -\log P(\mathbf{y}^{(i)}\mid\mathbf{x}^{(i)}) −logP(Y∣X)=i=1∑n​−logP(y(i)∣x(i))

对于单个样本，分类损失可以写成：

l(y,y^)=−∑j=1qyjlog⁡y^jl(\mathbf{y},\hat{\mathbf{y}}) = -\sum_{j=1}^{q}y_j\log \hat{y}_j l(y,y^​)=−j=1∑q​yj​logy^​j​

这个损失函数称为交叉熵损失（cross-entropy loss）。

如果标签是 one-hot 向量，那么只有真实类别对应的那一项会保留下来。

例如真实类别为 ccc 时：

l(y,y^)=−log⁡y^cl(\mathbf{y},\hat{\mathbf{y}}) = -\log \hat{y}_c l(y,y^​)=−logy^​c​

这表示：模型给真实类别分配的概率越大，损失越小；如果模型给真实类别分配的概率接近 111，损失接近 000。

进一步的：

我们将 softmax 代入交叉熵损失，有：

考虑相对于任何未规范化的预测 ojo_joj​ 的导数，我们得到：

∂ojl(y,y^)=exp⁡(oj)∑k=1qexp⁡(ok)−yj=softmax(o)j−yj\partial_{o_j} l(\mathbf{y}, \hat{\mathbf{y}}) = \frac{\exp(o_j)}{\sum_{k=1}^q \exp(o_k)} - y_j = \mathrm{softmax}(\mathbf{o})_j - y_j ∂oj​​l(y,y^​)=∑k=1q​exp(ok​)exp(oj​)​−yj​=softmax(o)j​−yj​

这与我们在回归中看到的形式相似，其中梯度是 yyy 和 y^\hat{y}y^​ 之间的差异。

这不是巧合，在任何指数族分布模型中，对数似然的梯度正是由此得出的。这使得梯度计算在实践中变得容易很多。

交叉熵损失的信息论解释

信息论用于研究信息的编码、解码、传输和压缩。

熵

分布 PPP 的熵定义为：

H[P]=∑j−P(j)log⁡P(j)H[P] = \sum_j -P(j)\log P(j) H[P]=j∑​−P(j)logP(j)

信息论的基本定理之一指出，为了对从分布 ppp 中随机抽取的数据进行编码，至少需要 H[P]H[P]H[P] 纳特（nat） 进行编码。

纳特对数底为 eee 而不是 222 ，因此 111 个纳特是 1log⁡(2)≈1.44\frac{1}{\log(2)} \approx 1.44log(2)1​≈1.44 比特。

信息量

事件 jjj 的信息量可写为：

−log⁡P(j)-\log P(j) −logP(j)

如果一个事件概率很高，它发生时并不令人意外，信息量较小；如果一个事件概率很低，它发生时更“意外”，信息量较大。

交叉熵

交叉熵 H(P,Q)H(P,Q)H(P,Q) 可以理解为：真实分布为 PPP，但使用主观分布 QQQ 进行编码或预测时的平均信息量。

更直观的，可以理解为“主观概率为 QQQ 的观察者在看到根据概率 PPP 生成的数据时的预期惊异”。

当 P=QP=QP=Q 时，交叉熵达到最小值：

H(P,P)=H(P)H(P,P)=H(P) H(P,P)=H(P)

因此，交叉熵分类目标可以从两个角度考虑：

  1. 最大化真实标签的似然；
  2. 最小化用模型预测分布描述真实标签所需的信息量。

模型预测与评估

softmax 回归训练完成后，模型会为每个样本输出一个类别概率分布。

预测类别通常取概率最大的类别：

c^=argmax⁡jy^j\hat{c} = \operatorname*{argmax}_j \hat{y}_j c^=jargmax​y^​j​

accuracy=正确预测的样本数样本总数\mathrm{accuracy} = \frac{\text{正确预测的样本数}}{\text{样本总数}} accuracy=样本总数正确预测的样本数​
